Quiet Windows 11 Setup

Windows 11 Pro 25H2 · build 26200.x Local account · EEA device region · researched 2026-09-27

A clean install for programming and gaming with minimal bloatware, telemetry, ads and AI. Everything uses built-in tools: Settings, gpedit.msc, policy registry keys and PowerShell. Tick the steps as you go; your ticks are saved in this browser.

Before you start

  • Intel PTT or AMD fTPM, UEFI mode (CSM off), VT-d or AMD-Vi. Update an old BIOS first. Anti-cheat needs TPM and Secure Boot.

  • Setup runs offline, so you may need the LAN or Wi-Fi driver afterwards.

  • Download from microsoft.com/software-download/windows11. Don't use modified ISOs. 24H2 Home/Pro stops getting updates on 13 Oct 2026. 26H2 will arrive later as a small update.

01

Build autounattend.xml

The old local-account bypasses (oobe\bypassnro, ms-cxh:localonly) no longer work. An answer file that pre-defines the local account does work on retail 25H2 Pro. Generator: schneegans.de/windows/unattend-generator

Region = Ireland (EEA). Setup saves the region you pick as the device region, and the EU's DMA rules then unlock extra options: Bing can be removed from Search, Edge can be uninstalled, the Widgets feed can be turned off, almost all inbox apps can be removed, and the automatic Microsoft 365 Copilot install doesn't apply.

Changing Settings → Region later doesn't change the device region. Set your real country for Store, billing and formats after install (step 03).

  • Method A: standard stick (Media Creation Tool, or Rufus in plain mode). Copy autounattend.xml to the root of the stick, next to setup.exe.

    Method B: Ventoy stick. Leave the ISO unchanged; Ventoy's auto-install plugin passes the file to Setup. Lay out the data partition like this:

    /ISO/Win11_25H2_x64.iso            <- your ISO (any folder / name)
/ventoy/script/autounattend.xml    <- the generated answer file
/ventoy/ventoy.json                <- plugin config (create it)

    Create /ventoy/ventoy.json. Paths start at the root of the stick and must match your real file names. If a ventoy.json already exists, add the block to it. VentoyPlugson.exe → Auto Install Plugin does the same without editing JSON.

    {
  "auto_install": [
    {
      "image": "/ISO/Win11_25H2_x64.iso",
      "template": "/ventoy/script/autounattend.xml"
    }
  ]
}

    Before you boot: update Ventoy to the latest version. With Secure Boot on, enroll Ventoy's key once: on the blue MOK screen choose Enroll key from disk → VTOYEFI → ENROLL_THIS_KEY_IN_MOKMANAGER.cer → Continue → Yes → Reboot. Some PCs also need "Allow Microsoft 3rd Party UEFI CA" in the firmware. If it still won't boot, turn Secure Boot off for the install only and back on right after.

Don't tick
  • Remove Microsoft Store (it also updates Notepad, Paint, Terminal, winget and codecs)
  • Disable Defender, Windows Update, SmartScreen, UAC or Smart App Control, or pause updates
  • "Xbox Apps", which also removes Xbox Identity Provider and TCUI. Step 04 removes only the Xbox app and Game Bar.
  • Remove WebView2, or bypass the TPM, Secure Boot and CPU checks
02

Install

  • Method A: Setup picks up the file automatically. Method B (Ventoy): select the ISO, then choose the /ventoy/script/autounattend.xml template in Ventoy's menu, not "Boot without auto installation template".

    Leave every other disk alone. With Ventoy, the USB stick itself also appears in the disk list.

  • This screen means the answer file wasn't used. With Ventoy, check the paths in ventoy.json. To finish anyway, choose Set up for work or school → Sign-in options → Domain join instead.

03

First boot, in this order

  • You should never have seen a Microsoft-account screen, and these logs should exist: C:\Windows\Setup\Scripts\Specialize.log, DefaultUser.log and FirstLogon.log. If they're missing, the generator's tweaks didn't run, but step 04 onwards still covers the essentials.

  • Enable-ComputerRestore -Drive "C:\"
Checkpoint-Computer -Description "Clean install" -RestorePointType MODIFY_SETTINGS

  • Settings → Time & language → Language & region → Country or region. The device region stays EEA, which is what you want.

  • Real-time protection, cloud protection and tamper protection on. Reputation-based protection on. Core isolation → Memory integrity on, since anti-cheat increasingly requires it.

  • Settings → System → Activation should say "active with a digital license".

04

Remove leftover inbox apps

Run this in Windows PowerShell 5.1 as admin. It removes exact package names only and skips any that aren't installed.

  • # Apps to remove (exact package names). Missing ones are simply skipped.
$remove = @(
  'Clipchamp.Clipchamp',
  'Microsoft.BingNews', 'Microsoft.BingWeather', 'Microsoft.BingSearch',
  'Microsoft.MicrosoftOfficeHub',        # "Microsoft 365 Copilot" app
  'Microsoft.Copilot',                   # Copilot app
  'Microsoft.OutlookForWindows',         # new Outlook
  'MSTeams',
  'Microsoft.Todos',
  'Microsoft.PowerAutomateDesktop',
  'Microsoft.MicrosoftSolitaireCollection',
  'Microsoft.GetHelp',
  'Microsoft.Getstarted',                # Tips
  'Microsoft.WindowsFeedbackHub',
  'Microsoft.WindowsMaps',
  'Microsoft.Windows.DevHome',           # retired in 2025
  'Microsoft.GamingApp',                 # Xbox app (you use Steam/Epic)
  'Microsoft.XboxGamingOverlay'          # Game Bar
)

foreach ($name in $remove) {
  Get-AppxPackage -AllUsers -Name $name | Remove-AppxPackage -AllUsers -ErrorAction SilentlyContinue
  Get-AppxProvisionedPackage -Online | Where-Object DisplayName -eq $name |
    Remove-AppxProvisionedPackage -Online -ErrorAction SilentlyContinue | Out-Null
}

    Optional extras: MicrosoftCorporationII.QuickAssist, Microsoft.YourPhone, MicrosoftWindows.CrossDevice, Microsoft.ZuneMusic, Microsoft.WindowsSoundRecorder, Microsoft.WindowsAlarms, Microsoft.MicrosoftStickyNotes.

reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\GameDVR" /v AppCaptureEnabled /t REG_DWORD /d 0 /f

  • Install and set your default browser first, e.g. winget install --id Mozilla.Firefox. Keep the WebView2 Runtime.

Keep

  • XboxIdentityProvider, Xbox.TCUI, the WebView2 Runtime, Terminal, Notepad, Paint, Snipping Tool and Photos
05

Telemetry

On Pro, the lowest diagnostic data level is "Required" (AllowTelemetry=1). Setting it to 0 does nothing on Pro. Everything optional can be turned off.

  • Turn off optional diagnostic data, inking and typing, and viewing diagnostic data. Click Delete diagnostic data. Set Feedback frequency to Never.

  • $dc = 'HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection'
reg add $dc /v AllowTelemetry /t REG_DWORD /d 1 /f
reg add $dc /v DisableTelemetryOptInSettingsUx /t REG_DWORD /d 1 /f
reg add $dc /v DisableDiagnosticDataViewer /t REG_DWORD /d 1 /f
reg add $dc /v DoNotShowFeedbackNotifications /t REG_DWORD /d 1 /f
reg add "HKCU\Software\Policies\Microsoft\Windows\CloudContent" /v DisableTailoredExperiencesWithDiagnosticData /t REG_DWORD /d 1 /f
$sys = 'HKLM\SOFTWARE\Policies\Microsoft\Windows\System'
reg add $sys /v EnableActivityFeed /t REG_DWORD /d 0 /f
reg add $sys /v PublishUserActivities /t REG_DWORD /d 0 /f
reg add $sys /v UploadUserActivities /t REG_DWORD /d 0 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\InputPersonalization" /v AllowInputPersonalization /t REG_DWORD /d 0 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\TextInput" /v AllowLinguisticDataCollection /t REG_DWORD /d 0 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AdvertisingInfo" /v DisabledByGroupPolicy /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v AllowCloudSearch /t REG_DWORD /d 0 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\FindMyDevice" /v AllowFindMyDevice /t REG_DWORD /d 0 /f

  • LocationAndSensors\DisableLocation=1 breaks automatic time zone. Windows Error Reporting\Disabled=1.

Skip
  • Disabling the DiagTrack service (⚠ undocumented and low value) or any other service. Blocking Microsoft servers with the hosts file or firewall.

08

Windows Update hygiene

  • This is how new features, often AI ones, arrive early. Security fixes still install.

  • reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization" /v DODownloadMode /t REG_DWORD /d 0 /f

    Never disable the DoSvc service or use mode 100.

  • Set "Do not include drivers with Windows Updates" (ExcludeWUDriversInQualityUpdate=1). The trade-off: you then keep every driver up to date yourself.

Programming

  • Turn on long paths and sudo (in a new window). Turn on file extensions, hidden files, full path in the title bar and End task. Allow local PowerShell scripts and set Terminal as the default. Turn on Developer Mode only if you need it.

    Avoid sudo's "Input closed" and "Inline" modes.

  • System → Storage → Advanced storage settings → Disks & volumes → Create Dev Drive. Check it with fsutil devdrv query D:. Put repos, caches and build output there.

Gaming

  • System → Display → Graphics. It's required for DLSS Frame Generation.

  • High Performance gains about 0–2 FPS, and Ultimate Performance is no better.

  • Riot Vanguard, FACEIT, EA Javelin (Battlefield 6) and Call of Duty require them. FACEIT requires Windows 11 from 14 Oct 2026.

Avoid

  • AtlasOS, ReviOS, Tiny11 core, MicroWin and Win11 Creator ISOs

Audit (read-only)

Run this after setup and after every feature update. "Stopped" services are fine; only "Disabled" is a problem. If anything shows as RETURNED, repeat step 04. If anything shows as MISSING or WRONG, re-apply that section.

  • Write-Host "`n== Core services (StartType must not be Disabled) ==" -ForegroundColor Cyan
Get-Service wuauserv, UsoSvc, BITS, CryptSvc, DoSvc, WinDefend, SecurityHealthService, InstallService, AppXSvc, ClipSVC |
  Select-Object Name, Status, StartType | Format-Table -AutoSize

Write-Host "== Defender ==" -ForegroundColor Cyan
Get-MpComputerStatus | Select-Object AMServiceEnabled, AntivirusEnabled, RealTimeProtectionEnabled, IsTamperProtected, AntivirusSignatureLastUpdated | Format-List

Write-Host "== Secure Boot / TPM / VBS ==" -ForegroundColor Cyan
"Secure Boot: " + (Confirm-SecureBootUEFI)
Get-Tpm | Select-Object TpmPresent, TpmReady | Format-List
$dg = Get-CimInstance -Namespace root\Microsoft\Windows\DeviceGuard -ClassName Win32_DeviceGuard
"VBS running: " + ($dg.VirtualizationBasedSecurityStatus -eq 2)
"Memory integrity (HVCI) running: " + ($dg.SecurityServicesRunning -contains 2)

Write-Host "== Must be present ==" -ForegroundColor Cyan
'Microsoft.WindowsStore','Microsoft.StorePurchaseApp','Microsoft.DesktopAppInstaller','Microsoft.SecHealthUI' | ForEach-Object {
  "{0,-35} {1}" -f $_, [bool](Get-AppxPackage -Name $_) }

Write-Host "== Must be absent (bloat) ==" -ForegroundColor Cyan
$bloat = 'Clipchamp.Clipchamp','Microsoft.BingNews','Microsoft.BingWeather','Microsoft.BingSearch',
  'Microsoft.MicrosoftOfficeHub','Microsoft.Copilot','Microsoft.OutlookForWindows','MSTeams','Microsoft.Todos',

  'Microsoft.WindowsFeedbackHub','Microsoft.WindowsMaps','Microsoft.Windows.DevHome','Microsoft.GamingApp','Microsoft.XboxGamingOverlay'

$found += Get-AppxProvisionedPackage -Online | Where-Object { $bloat -contains $_.DisplayName } | Select-Object -ExpandProperty DisplayName
